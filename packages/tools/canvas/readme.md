# 画布操作

让 Agent 直接操作项目中打开的画布，搭建和整理节点流程。

## 使用方式

先打开目标项目的画布，再向 Agent 描述希望完成的操作。
例如：“把当前画布整理整齐”“添加一个文本节点写入这段分镜”“把这张参考图接到视频生成节点”。
Agent 会先读取实际节点和可用能力，再执行操作；已有节点可以继续复用。

## 支持的功能

- 新建、切换和重命名画布。
- 添加节点；批量移动、重命名、选择和删除节点，一次可处理多个节点。
- 批量连接兼容的节点端口，批量删除指定连线。
- 根据节点尺寸与连线自动整理整张画布，或调整视图展示指定节点。
- 调用节点提供的功能，例如修改文本、设置提示词或生成媒体；具体以该节点支持的功能为准。
- 按装配计划批量落地资产节点与参考连线，并按分层逐层发起生成。

## 装配与分层生成

先用计划工具的 assemble 动作产出装配计划，再把其中的 assetNodes、clipNodes、layers 原样交给 `assembleCanvas`：
它按 layer 从 0 往上逐层建节点、按计划 edges 的顺序连线，并把该顺序写进节点的参考顺序（`{{ref N}}` 的编号来源），
ratio、duration、resolution 等依赖模型的字段会列在 deferredSeeds 里，等选好模型后再下发。

之后用 `generateLayer` 按层推进：`action=start` 只发起并立即返回，`action=status` 轮询，`action=cancel` 请求停止。
本层之前还有节点未成功时，start 会直接拒绝并列出阻塞节点，保证基础图先于依赖它的分镜图和视频生成。

需要保持目标画布可用。新增节点的类型取决于当前安装的节点插件，连线也须满足节点的输入要求。
节点生成任务启动后仍需等待实际结果；自动整理画布不会触发生成。
本工具没有配置项，无需单独填写 API Key；媒体生成所需配置由对应供应商提供。
