# 资产卡模板

> 权威依据：[assets/assetCardWorkflowPlan.md](../../../../docs/assetCardWorkflowPlan.md) §1.2。编号与参考规则见 [参考接线解析规则](referenceResolution.md)。

## 一、编号体系

| 前缀 | 类型 | 默认画幅 | 说明 |
|---|---|---|---|
| `C` | 人物角色卡 | 2:3 | 可带状态后缀 `C01-A`、`C01-Y` |
| `SC` | 场景卡（空镜） | 16:9 | 无人场景；人只在有人的分镜出现 |
| `P` | 道具卡 | 1:1 | 可带状态后缀 `P01-A`（新）、`P01-B`（旧） |
| `KF` | 关键帧/构图卡 | 9:16 | 构图参考，引用上述基础资产 |
| `S` | 声音资产 | — | 仅文字记录，不出图 |

规则：

- **状态后缀属身份**：`C01-A` 与 `C01` 是两张卡，必须保持独立；未声明的后缀卡默认继承同前缀基卡。
- **编号全局唯一**：同一文件内重复必须报错并指出两处行号，不合并、不重新分配。
- **解析宽口径**：`C1`、`c01-b` 均按编号接受（不强制补零、后缀大小写不敏感），写入索引时统一规范化。
- 画幅三档搜索：单卡 `建议画幅` > 节标题声明 > 前缀默认值。

## 二、标题行（唯一权威格式）

```markdown
### C01 · 淳于棼（青年）
```

- `#` 可 1–6 级，也可省略；分隔符接受 `·` `|` `｜` `:` `：` 或空格。
- 名称里可带 `｜出场段：65` 这类元数据尾巴，解析时剥掉，不进名称。
- **不用表格、不用列表项承载编号**，避免格式漂移。

## 三、字段与别名链

| 字段 | 接受的别名 | 必填 |
|---|---|---|
| 提示词 | `提示词` / `人物提示词` / `场景提示词` / `道具提示词` / `资产提示词` / `图片提示词` | 是（`文本类` 卡除外） |
| 负面提示词 | `负面提示词` / `可选负面提示词` | 否 |
| 建议画幅 | `建议画幅` / `画幅` | 否 |
| 身份参考（C） | `身份参考` / `参考` | 否 |
| 结构参考（SC） | `结构参考` / `空间参考` | 否 |
| 道具参考（P） | `道具参考` / `器物参考` | 否 |
| 参考派生 | `参考派生` / `参考派生说明` / `派生参考` | 否 |
| 文本类 | `文本类` / `仅文字记录` / `不引用独立图片` | 否（置位则不出图） |

- 标签可用中文或英文冒号，可加 `**` 或反引号包裹。
- 值可为多行，直到下一个标签行或下一张卡标题。
- 字段必须出现在卡片块内（下一张卡标题之前）。

## 四、全局设置（首个卡片标题之前）

```markdown
- 风格统一词：写实电影质感，自然光，胶片颗粒
- 统一人物质感词：皮肤有细微毛孔，发丝根根分明
- 统一时代设定：民国初年
- 统一排除项：文字、水印、畸形手指
```

别名：`统一画风词` / `统一画面风格` / `统一时代设定` / `时代背景` / `统一排除项`。
`统一人物质感词` 仅追加到人物卡，避免空镜出现人。

## 五、完整样例

```markdown
# 资产卡 · 南柯一梦

## 全局设置
- 风格统一词：写实仙侠电影质感，自然光，胶片颗粒
- 统一人物质感词：皮肤质感细腻，发丝根根分明
- 统一排除项：文字、水印、现代服装

## 人物资产卡
### C01 · 淳于棼（青年）
- 建议画幅：2:3
- 提示词：青年沈砚，素色圆领袍，束发，面容清瘦，剑眉，正面半身
- 负面提示词：多手，多余手指

### C02 · 淳于棼（重伤）
- 身份参考：C01（同一张脸，带伤）
- 提示词：同一张脸的青年沈砚，面色苍白，左颊一道血痕，衣袍破损

## 场景资产卡（SC01–SC12，16:9 横屏）
### SC01 · 古槐树下
- 提示词：唐代古风庭院，一株巨大古槐，树冠遮天，地面落满槐花，空镜无人
- 文本类：空镜，不出现人物

## 道具资产卡
### P01 · 八仙桌（新）
- 提示词：新作榆木八仙桌，木质紧实，无磨损

### P02 · 八仙桌（旧）
- 道具参考：P01（同一张桌子，用久成旧）
- 提示词：同一张八仙桌，桌面磨损发亮，边角磨圆，腿部磕碰痕

## 关键帧/构图卡
### KF01 · 入梦
- 提示词：9:16 竖构图，C01 躺下，SC01 背景，P01 放在床头（引用 C01、SC01、P01）
```

## 六、角色分离（谁都不能越界）

| 角色 | 来源 | 用于 |
|---|---|---|
| 人物母版 `C*` | 图片生成节点 | 身份锚点，只锁脸与稳定外观 |
| 场景空镜 `SC*` | 图片生成节点 | 空间结构，保持无人 |
| 道具母版 `P*` | 图片生成节点 | 形制与结构，无人手 |
| 构图卡 `KF*` | 图片生成节点 | **只做构图参考，不正当首帧** |
| 分镜格 | 图片生成节点 | 动作依据，未经人工验收不得回流为参考 |
| 视频段 | 视频生成节点 | 一段一节点 |

禁止：拿风格图当资产、把三视图连成三个角色、把分镜图当脸部参考、把 `KF` 卡当母版接入视频。
