# 资产卡模板

> 权威依据：[assets/assetCardWorkflowPlan.md](../../../../docs/assetCardWorkflowPlan.md) §1.2。编号与参考规则见 [参考接线解析规则](referenceResolution.md)，提示词写法见 [图片提示词规范](imagePrompt.md)，设计维度与验收见 [资产设计维度与验收](assetDesign.md)。

## 一、编号体系

| 前缀 | 类型 | 默认画幅 | 说明 |
|---|---|---|---|
| `C` | 人物角色卡 | 16:9（四视图整版·2K） | 可带状态后缀 `C01-A`、`C01-Y`；**只有四视图整版一种版面**，一张图横向四栏 ①半身像 ②正面全身 ③90°侧面全身 ④背面全身（§五、[imagePrompt.md](imagePrompt.md) §5.1） |
| `SC` | 场景卡（空镜） | 16:9 | 无人场景；人只在有人的分镜出现 |
| `P` | 道具卡 | 1:1 | 可带状态后缀 `P01-A`（新）、`P01-B`（旧） |
| `KF` | 关键帧/构图卡 | 9:16 | 构图参考，引用上述基础资产；「导入资产与分镜」节点**不自动抽取** KF 卡，需人工补写 |
| `S` | 声音资产 | — | 仅文字记录，不出图；每个说话人与画外旁白各一张，正文写一句稳定音色描述（可带状态后缀 `S01-A`：不同年龄/状态声线） |

规则：

- **状态后缀属身份**：`C01-A` 与 `C01` 是两张卡，必须保持独立；未声明的后缀卡默认继承同前缀基卡。
- **编号全局唯一**：同一文件内重复必须报错并指出两处行号，不合并、不重新分配。
- **解析宽口径**：`C1`、`c01-b` 均按编号接受（不强制补零、后缀大小写不敏感），写入索引时统一规范化。
- 画幅三档搜索：单卡 `建议画幅` > 节标题声明 > 前缀默认值。
- **`C` 卡一律写 `建议画幅：16:9`**。旧版模板把 `C` 默认写成 `2:3`，那是历史写法（`2:3` 根本不在 `freevideo-image` 的五种比例里）：解析器仍按 [imagePrompt.md](imagePrompt.md) §三 的回落表接受，但新卡不要再写 `2:3`，也不要为了省尺寸退回单视图/三视图。

## 二、标题行（唯一权威格式）

```markdown
### C01 · 淳于棼（青年）
```

- `#` 可 1–6 级，也可省略；分隔符接受 `·` `|` `｜` `:` `：` 或空格。
- 名称里可带 `｜出场段：65` 这类元数据尾巴，解析时剥掉，不进名称。
- **不用表格、不用列表项承载编号**，避免格式漂移。

## 三、字段与别名链

| 字段 | 接受的别名 | 必填 |
|---|---|---|
| 提示词 | `提示词` / `人物提示词` / `场景提示词` / `道具提示词` / `资产提示词` / `图片提示词` / `视频提示词` | 是（`文本类` 卡除外）。写法见 [imagePrompt.md](imagePrompt.md)，设计维度与验收见 [assetDesign.md](assetDesign.md) |
| 负面提示词 | `负面提示词` / `可选负面提示词` | 否 |
| 建议画幅 | `建议画幅` / `画幅` | 否 |
| 身份参考（C） | `身份参考` / `参考` | 否 |
| 结构参考（SC） | `结构参考` / `空间参考` | 否 |
| 道具参考（P） | `道具参考` / `器物参考` | 否 |
| 参考派生 | `参考派生` / `参考派生说明` / `派生参考` | 否 |
| 文本类 | `文本类` / `仅文字记录` / `不引用独立图片` | 否（置位则不出图） |

- 标签可用中文或英文冒号，可加 `**` 或反引号包裹。
- 值可为多行，直到下一个标签行或下一张卡标题。
- 字段必须出现在卡片块内（下一张卡标题之前）。

## 四、全局设置（首个卡片标题之前）

```markdown
- 风格统一词：写实电影质感，自然光，胶片颗粒
- 统一人物质感词：皮肤有细微毛孔，发丝根根分明
- 统一时代设定：民国初年
- 统一排除项：文字、水印、畸形手指
```

别名：`统一画风词` / `统一画面风格` / `统一时代设定` / `时代背景` / `统一排除项`。
`统一人物质感词` 仅追加到人物卡，避免空镜出现人。

## 五、完整样例

```markdown

- 统一人物质感词：皮肤质感细腻，发丝根根分明
- 统一排除项：文字、水印、现代服装

## 人物资产卡（C01–C12，16:9 四视图整版）
### C01 · 淳于棼（青年）
- 建议画幅：16:9
- 提示词：角色设定图，四视图版面：横向等分四栏，栏间留白；从左到右依次为半身像、正面全身、90° 侧面全身、背面全身。半身像为正面、头顶贴齐栏顶、画面裁到腰、面部结构清晰可辨、人物按上半身放大；正面、侧面、背面三栏共用同一全身比例尺、按脚底线对齐、头顶自然等高。青年沈砚，素色圆领袍，束发，面容清瘦，剑眉
```

## 六、角色分离（谁都不能越界）

| 角色 | 来源 | 用于 |
|---|---|---|
| 人物母版 `C*` | 图片生成节点 | 身份锚点，只锁脸与稳定外观 |
| 场景空镜 `SC*` | 图片生成节点 | 空间结构，保持无人 |
| 道具母版 `P*` | 图片生成节点 | 形制与结构，无人手 |
| 构图卡 `KF*` | 图片生成节点 | **只做构图参考，不正当首帧** |
| 分镜格 | 图片生成节点 | 动作依据，未经人工验收不得回流为参考 |
| 视频段 | 视频生成节点 | 一段一节点 |

禁止：拿风格图当资产、把旧版三视图/单视图的几张图连成三个角色、把分镜图当脸部参考、把 `KF` 卡当母版接入视频。

## 七、产出去向：`plan/assetIndex.json` 与画布节点 label

正常路径不让 Agent 手写派生文件：画布上的「导入资产与分镜」节点（`packages/nodes/assetImportNode`，节点 type `remote-assetImportNode`，agent 侧工具 `node:importScript`）按本模板的编号与字段抽取，独占写下面两个文件。

- `plan/assetIndex.json` = `{ "version": "assetIndex-v1", "cards": [{ id, name, kind, textOnly, nodeId }] }`（`packages/nodeShared/src/mtrack/mtrackProject.ts:128-139`）。`id` 是卡片编号（大写 `C01` / `SC01` / `P01`，`S` 类只记文字）；`kind` 取 `character` / `scene` / `prop` / `sound`；`textOnly: true` 不出图；`nodeId` 指向**已出图的图片节点**，没出图或文本类卡为 `null`（V13 只认已出图资产）。
- 画布资产节点的 label 必须写成 **`<代号> <名称>`**（如 `C01 淳于棼（青年）`）：派工侧按 label 前缀认卡片编号（`packages/nodeShared/src/mtrack/directDispatch.ts:208-212` 的 `labelMatchesCard`），label 丢了编号会被判成「非资产卡」，多轨「参考素材」里只显示无预览、勾不上。
- 导入时**代码确定性拦下的只有两条**：编号唯一（重复即报错）、分镜引用的卡不在本次抽取里（落盘前掐掉该引用，不带着缺失参考进场）；「场景卡空镜无人 / 道具卡无手」只是内置抽取提示词的要求（`packages/nodes/assetImportNode/src/assetImport.ts` 的 `extractionSystemPrompt`），**不是落盘校验**，出图后要人眼核。
- 落盘是独占写：`plan/story.mtrack` 或 `plan/assetIndex.json` 任一已存在就整体拒绝，不追加不合并；想在原工程上继续就 `node:bindProject(mode:"open")`，想重来先手动改名/清理（占用探测在 `importAssets` 入口做，重跑立刻被拒，不会先烧模型）。
- 单张出图失败不中断整条导入：已出的图与节点保留，失败卡在索引里的 `nodeId` 仍为 `null`（补一张即可），失败清单随摘要返回 `failed: [{ id, reason }]`，面板与 `node:importStatus` 都能读到。
