# 资产设计维度与验收

> 本文件只回答三件事：**一项资产要设计哪些维度、编号与记录落在哪里、出图前后怎么验收**。
> 提示词怎么写（三类模板、一致性锚点短语、负向词表）见 [图片提示词规范](imagePrompt.md)；字段名、别名、标题行语法、画幅三档搜索见 [资产卡模板](assetCardTemplate.md)；参考关系解析与四道守卫见 [参考接线解析规则](referenceResolution.md)。
> 权威依据：[docs/assetCardWorkflowPlan.md](../../../../docs/assetCardWorkflowPlan.md) §1.2。v1.1.8 的旧设计文档 `packages/skills/v118workflow/references/knowledge/assetDesign.md` 已冻结为历史参考，不再作为本技能的规范来源。

## 一、记录落点（唯一）

| 内容 | 位置 | 说明 |
|---|---|---|
| 资产卡主记录 | `assets/assetCards.md` | **唯一真源**，角色/场景/道具/关键帧/声音卡全部写这里；卡片在文件中的先后顺序即依赖顺序 |
| 资产索引 | `plan/assetIndex.json` | 派生产物，由 `planOperator` 的 `resolve` / `build` 产出，不手改、不手写 |
| 生成与验收状态 | `plan/story.mtrack` | 生成/选用/验收状态只写这里，`generated` 不等于交付完成 |
| 出图落点 | `assets/<nodeId>/` | 图片文件本身；协议不写图片路径进卡片 |

- **不写 `画布/资产.json`**：那是 v1.1.8 旧体系的资产画布记录，与本技能的 `assets/assetCards.md` 不是同一个东西。新项目一律不建、不写、不引用它，也不要两边各存一份设计。
- **三种信息分清**：剧本明确事实、用户给定参考、待确认的美术选择。未知发型、服装或结构可以提出具体方案，但必须在卡片里标成提案；提案不能当事实喂给下游。
- 先确认可复用的设计，再写提示词。基础角色、空间布局或画风一改，下游变体与分镜全部受影响：记录受影响项并回到确认点处理，不能覆写主记录后假装下游仍然有效。

## 二、编号契约（摘要）

| 前缀 | 类型 | 默认画幅 | 关键约束 |
|---|---|---|---|
| `C` | 人物角色卡 | 2:3 | 可带状态后缀 `C01-A`、`C01-Y` |
| `SC` | 场景卡（空镜） | 16:9 | 无人场景，人只在有人的分镜出现 |
| `P` | 道具卡 | 1:1 | 可带状态后缀 `P01-A`（新）、`P01-B`（旧） |
| `KF` | 关键帧/构图卡 | 9:16 | 只做构图参考，不做首帧、不做母版 |
| `S` | 声音资产 | — | 仅文字记录，不出图 |

- **画幅是契约值，比例要落到引擎实际支持的五档**：`freevideo-image` 只接受 `1:1`、`16:9`、`9:16`、`4:3`、`3:4`。因此 `C` 卡的 2:3 在出图时统一取 **16:9（四视图整版）**——角色卡只有四视图一种版面，不切成单视图；`SC` 走 16:9，`P` 走 1:1，`KF` 走 9:16。卡片里仍按默认画幅写，不因为引擎比例去改编号体系。
- **状态后缀属身份**：`C01-A` 与 `C01` 是两张卡，各自独立；未声明的后缀卡默认继承同前缀基卡（回落规则见参考接线解析规则 §四）。
- **编号全局唯一**：重复即报错，不合并、不重新分配；宽口径书写（`C1`、`c01-b`）在写入索引时统一规范化。
- **顺序即依赖**：父卡写在引用它的卡之前（backwards-only），前向引用会被解析器直接拒绝。需要前向引用时改卡片顺序，不要造别名绕过。
- 字段与别名以 [资产卡模板](assetCardTemplate.md) §三为准，本文件不复述别名表。

## 三、角色：先辨识，再造型

### 3.1 版面：只有四视图，第一栏是半身像

角色卡只有**一种版面**：一张四视图设定图，同一画面从左到右依次为

1. **半身像**：正面、腰部以上、面部结构清晰（这是第一栏，也是身份的锚点栏，面部结构全部由它承担）；
2. **正面全身**：服装正面形制、裤/裙/靴与整体比例靠这一栏核对；
3. 侧面全身（约 90°）；
4. 背面全身（约 180°）。

- **半身像与全身栏不共用比例尺**：半身像栏头顶贴齐栏顶、画面裁到腰、人物单独放大；正面、侧面、背面三个全身栏按**脚底线**对齐、共用同一全身比例尺（半身像不参与这套比例尺，也不要按肩线去对齐）。不写明这条，模型会把半身像也画成全身，四栏全部变成同一景别。
- 四栏是同一人、同一发型、同一体型、同一套衣服、同一状态；侧背结构互相对应，不裁发饰、衣摆和鞋。
- 整版用 `16:9` + `2K`（1K 下每栏约 256px，脸和手不可用，只能当预览）。具体版面比例、留白与提示词写法见 [图片提示词规范](imagePrompt.md)。
- **旧的「三视图」「单视图」以及「特写＋完整三视图」版面一律作废**（v118 `knowledge/assetDesign.md` 第 44 行、`workflow/references/assets.md` 第 26 行的写法均为历史），不再作为可选版面，也不得用「出图方便」为由降级成三视图或单张。

### 3.2 面部特征（跨角度可辨）

至少确定 **两三个换机位、换表情都还在的特征**，不同角色不得共享同一张模板脸。用结构化选项推导，不用「美丽/英俊/高质量」代替设计：

| 维度 | 可观察的选择 |
|---|---|
| 头脸轮廓 | 长/圆/方、颧骨与下颌关系、额头宽度、下巴形状 |
| 五官结构 | 眉形与眉距、眼裂形状与眼距、鼻梁转折、唇形、耳廓 |
| 肤发特征 | 设定决定的肤色、发际线、发色、长度、分缝、卷直、胡须 |
| 独特标记 | 小痣、疤痕、断眉、不对称细节；只放 1–2 个，多了会互相稀释 |

- 特征要「组合成立」而不是堆形容词：写「窄长脸 + 平眉 + 眼距偏宽」，不写「五官精致」。
- 保留自然皮肤纹理、碎发和适度不对称；真人分支不能修成广告模特。
- 气质从视线、眉眼放松程度、嘴角和站姿体现，基础图以中性微表情为主。

### 3.3 体型与站姿

- 记身高关系（相对同框角色）、体型、肩颈、重心和自然站姿；儿童、老人服从实际年龄，不套统一比例。
- 站姿要能复用：同一次棚拍/同一世界里的自然重心，不用假人式立正。
- 体型是身份的一部分：变体不得顺手改身高或胖瘦，确需改变（成长、伤病）时按 3.5 记录连续性。

### 3.4 造型分层

按层设计、按层锁定边界，换装才不会变成另一个人：

| 层 | 设计决定 | 保持边界 |
|---|---|---|
| 基础身份 | 已确认的脸、体型、肤发识别点、基准站姿 | 换装不改脸；明确变身需求另记允许改变的结构 |
| 妆容 | 素肌、日常、场合、盛典或剧情状态；眉眼、面颊、唇部的具体变化 | 道具、天气、动作词不自动触发浓妆；妆后仍认得出 |
| 发型/头饰 | 梳理、扎束、盘发、编发与必要发饰 | 发际线、发色、未授权长度不变；侧背结构能对应 |
| 内搭 | 领口、袖长、面料与颜色 | 层间关系合理，不穿插悬浮 |
| 主服/外套 | 时代、场合、温度、身份决定的廓形与剪裁 | 正侧背是同一件衣服，重量与褶皱符合材质 |
| 鞋与配饰 | 完整鞋款、腰带、首饰、眼镜、帽子、包袋 | 不漏鞋；配饰贴身，不漂浮、不嵌入皮肤 |

- 造型变化要有理由：居家晨起＝素肌＋松散发型；通勤＝适度整理＋合体衣物；正式会面＝加强剪裁与局部妆容。这是提案方法，**不自动给每个角色加妆或饰品**。
- 服装设定图不加入手持手机、咖啡杯、武器或剧情动作，这些由独立道具卡和分镜整合。

### 3.5 角色变体

- 以**已确认的父图**作真实身份参考（不是「参考某路径」的文字），写清 `不变：[脸/体型/发色/站姿]`、`仅改变：[妆容/发型/内搭/主服/鞋/配饰]`。
- 不要把所有层一次改完；一版只改声明项，其余沿用父图。
- 显著变身（换身体结构、重伤、年龄跨阶段）可以改，但必须记录识别连续性与新边界，并单独设卡，不覆盖原卡。

## 四、场景：建立可复用的空间

### 4.1 纵深层次

| 层次 | 设计内容 |
|---|---|
| 前景 | 门框、树枝、栏杆、家具边、纱帘等框架或遮挡，用来交代「从哪看进去」 |
| 中景 | 主要活动区域与固定陈设，人物实际行走、站位、对话的地方 |
| 后景 | 走廊、窗外、远山、街道延伸，交代空间边界与去向 |

- 先定观察高度与机位（平视、微俯、微仰），再排三层；不要用「电影感虚化」代替纵深设计。
- 单画面主视图交代清楚布局即可；只有剧情确实需要环视时才做多方向资料，且按 §六 的分辨率结论出图。
- 扁平/色块画风用遮挡、大小和色块分区表达前后，不强加写实景深。

### 4.2 遮挡关系

- 遮挡是空间证据：前景压住中景、中景压住后景，三层边界要对得上；同一空间换机位后，固定物件的相对位置仍然成立。
- 主体活动区不被切；人物站位与遮挡要能在分镜里直接使用，不靠后期猜。
- 低分辨率下虚化最容易糊掉遮挡边界，遮挡靠位置和明度差表达，不靠景深糊。

### 4.3 固定光照时段

- **主光必须有世界位置与来源**（哪面窗、哪盏灯、太阳在哪一侧），时段决定光色、光比和影长。
- 时段一旦确认就成为场景卡的固定属性；后续变体只改声明项，不悄悄换时段。

| 时段 | 主光与连带影响 |
|---|---|
| 清晨/上午 | 低角度侧光，长影，冷调环境＋暖侧光，窗光斜切地面 |
| 日间 | 自然漫射天光为主，阴影短而柔，室内靠窗一侧亮 |
| 黄昏 | 低暖侧逆光，长影，天空与地面出现冷暖过渡 |
| 夜晚 | 灯具/路灯成为主光，暗部保留轮廓与材质，不靠整体提亮 |
| 雨/雪 | 天光变平、对比降低，地面湿反射、玻璃挂水、空气透视变化 |

- 换机位时保持光源在世界中的位置，重新计算画面受光方向；不能把「画面左侧亮」当成所有机位的恒定规律。
- 空镜**不出现人物、人影、人体轮廓或剪影**；需要叙事时用符合剧本的生活痕迹（未推回的椅子、半杯水），不额外暗示未发生的事件。
- 场景变体按「时段 / 天气 / 明确的剧情状态」三类走；白昼转夜不能只换天空，晴转雨不能只加雨线，连带影响必须一起改。变体沿用父场景的视角与陈设，不能把换时段变成换地方。

## 五、道具：结构、材料与状态

### 5.1 结构与识别信息

只有具备独立剧情或视觉作用的物件才单独设卡，通用背景陈设留在场景里。写清用途、形状、尺寸关系、结构连接、主辅材质与状态，不用「精致道具」代替可检查的信息。

| 类别 | 重点识别信息 |
|---|---|
| 通讯/电子设备 | 机身轮廓、屏幕与按键、接口、保护壳、开关状态 |
| 餐饮器物 | 杯口、杯柄、容量、材质、内容物与必要的水汽/残留 |
| 办公/学习用品 | 封面、装订、页边、笔夹、工牌；文字只按剧情需要 |
| 饰品/信物 | 纹样、镶嵌、扣合、刻痕、独特缺口，以及为何能被认出 |
| 传统/幻想器物 | 时代工艺、木金玉陶等材料、形制与明确的特殊机制 |

- 展示版面按需要选：单张静物、正面＋侧面＋背面＋细节的 2×2，或用户已确认的版式；不为凑版式补没有用途的图。
- 道具独立摆放，**不出现人物、手、佩戴者或使用动作**；饰品可平放，武器工具可安全静置。

### 5.2 材质与痕迹因果

先定物件处于哪个状态（崭新、日常使用、长期使用、受损、封存），再选具体痕迹；同一材质的老化与损伤有先后顺序，不能给陶瓷生锈、给纸张写金属凹痕。

| 材质 | 正常质感 | 时间/使用痕迹 | 可读损伤或环境变化 |
|---|---|---|---|
| 金属 | 拉丝、锻造或抛光反射，边缘高光 | 接触区磨亮、微划痕、氧化 | 凹陷、弯折、断口、锈蚀；雨水成珠 |
| 木 | 木纹、漆面与裸木差异 | 包浆、漆面磨损、色泽变深 | 劈裂、断口、虫蛀或烧痕 |
| 纸 | 纤维、折痕、吸光表面 | 页边起毛、泛黄、反复翻阅 | 撕裂、缺角、浸湿起皱、墨迹洇开 |
| 织物 | 编织、绒感、垂坠与受力褶皱 | 褪色、起毛、受力处磨薄 | 撕裂、脱线、破洞、湿重贴附 |
| 陶瓷/玻璃 | 釉面柔光、通透与折射 | 杯口磨损、开片、手印水渍 | 缺口、裂缝、碎片、露胎、凝结 |
| 皮革 | 皮纹、柔硬、缝线与边油 | 弯折纹、包浆、边缘磨损 | 开裂、破口、表层剥落（五金单独变化） |
| 塑料/电子面板 | 合模线、哑光/亮面、屏幕反光 | 微划痕、褪色、按键区磨亮 | 崩边、裂口、变形、碎屏、显示故障 |

### 5.3 状态变化

- 状态档固定为：崭新 → 日常 → 长期使用 → 受损 → 封存。同一物件的状态变化**保持轮廓、核心纹样、结构锚点与展示机位**，只改允许项。
- 变化要一眼可辨、原因可追溯：为什么磨损、为什么有血、为什么少一角，都要能从剧情或使用方式解释。
- 互斥项不能同框：崭新与重度磨损、正常发光与无依据的魔法能量、完好与同部位又裂又锈。
- 关键残片保留可辨识部分；「被珍藏」通过包裹与反复开合痕迹表达，「贴身心爱」通过固定摩挲位置表达，不需要加入持有者的手。

## 六、画风适用范围（按 freevideo-image 实测能力）

前提：FreeVideo 官方指南只有视频任务（`t2va` / `i2va` / `fl2va` / `l2va` / `ref2va`），**图片生成没有官方提示词标准**，本节与 [图片提示词规范](imagePrompt.md) 都是 Toonflow 自定规范。

引擎硬约束（`packages/providers/src/media/freevideo.ts:225-231`、`:246`）：

| 项 | 实际能力 |
|---|---|
| 尺寸 | 只有 `1K` / `2K` |
| 比例 | 只有 `1:1`、`16:9`、`9:16`、`4:3`、`3:4` |
| 参考图 | 图片类最多 4 张（音频卡另计，不占这个名额） |
| 模式 | 文生图、单参考、多参考 |
| 负向参数 | 不单独暴露负向参数，排除项写进正文 |

画风类别沿用 v1.1.8 的十一种标识，但**不再绑定任何旧模型的专用写法**：不写「4K/8K」这类文字代替真实尺寸，不引用某模型专用的前缀文件或引用标记，不按旧模板固定 1:1 四格排布。每类在 1K / 2K 下的取舍如下：

| 画风类别 | 媒介 | 1K | 2K | 取舍 |
|---|---|---|---|---|
| `2D_flat_design` | 二维扁平/矢量 | ✅ 可交付 | ✅ 可交付 | 无写实纹理需求，1K 足够；不要硬加渐变与写实光影 |
| `2D_90s_japanese_anime` | 手绘赛璐璐 | ✅ 可交付 | ✅ 更稳 | 线条与色面 1K 成立；发丝、衣纹细节放 2K |
| `2D_chinese_guofeng` | 国风二维 | ⚠️ 单图可用 | ✅ 推荐 | 纹样、刺绣、窗棂结构 1K 会糊，多角色卡用 2K |
| `2D_mature_urban_romance` | 成熟都市动画 | ⚠️ 单图可用 | ✅ 推荐 | 微表情与眼神变化需 2K；1K 只做定妆不验收神态 |
| `3D_anime_render` | 风格化三维 | ⚠️ 草稿 | ✅ 推荐 | 体积与材质高光在 1K 容易塑料感 |
| `3D_chinese_traditional` | 国风三维 PBR | ❌ 只作草稿 | ✅ 必需 | 构造、包浆、接触阴影必须 2K 才可验收 |
| `3D_clay_stopmotion` | 黏土定格 | ✅ 可交付 | ✅ 更稳 | 指压痕、刻痕 2K 更清楚，1K 仍成立 |
| `3D_guofeng_cyber` | 国风赛博三维 | ❌ 只作草稿 | ✅ 必需 | 装置结构与发光位置细节多；多方向资料只用 2K |
| `realpeople_ancient_chinese` | 古风真人 | ⚠️ 草稿 | ✅ 推荐 | 皮肤纹理、织物纹理 1K 会被抹平 |
| `realpeople_modern_city` | 真人都市电影 | ⚠️ 草稿 | ✅ 推荐 | 毛孔、细纹、衣物褶皱是辨识线索，1K 会丢失 |
| `realpeople_urban_modern` | 都市甜宠写实 | ⚠️ 草稿 | ✅ 推荐 | 同上；强对比下 1K 暗部容易糊死 |

落地规则：

- **角色四视图排版固定**：整版 `16:9` + `2K`，第一栏半身像头顶贴齐栏顶、裁到腰、单独放大，其余三个全身栏按脚底线对齐。1K 只能当预览，不要为了省时间拆成三视图、单视图或两张各两视图——那会直接违反 §3.1 的唯一版面。
- 二维、扁平、黏土这类**低细节媒介**在场景单图与道具静物上 1K 就能定稿；三维、国风赛博、真人写实把 1K 当草图，正式资产走 2K（本机 GPU，耗时分钟级，一次到位比反复重出省）。角色四视图不适用 1K 例外。
- 参考图 ≤4 直接约束版面：身份参考 + 结构参考 + 道具参考合计不超 4 张。四视图是**一张图内的排版**，不占参考名额。
- 画风词只写与本次资产相关的维度（角色不塞城市空间词，场景不塞人物，道具不塞手）；风格词不替代角色个性，也不覆盖设定。

## 七、验收清单（可直接勾）

看**实际生成的图**再勾，不以「生成成功」代替视觉验收。

### 通用（每张资产图都要勾）

- [ ] **身份一致性**：名称/编号与卡片一致，跨角度是同一身份同一状态；变体只改声明项，未声明项沿用父图
- [ ] **无多余人物**：角色图没有其他角色，场景/道具图没有人物、人影、人体轮廓或手；群像数量与剧本一致
- [ ] **无文字水印**：无字幕、水印、标题卡、UI 覆盖、网格线、尺寸标注；剧情必需的文字按卡片保留且可读
- [ ] **构图完整**：头顶到脚底、器物整体完整入画，不裁发饰、衣摆、鞋、器底；四视图四栏齐全（半身像/正面全身/侧面/背面），无缺栏、无重复栏
- [ ] **参考图 ≤4**：图片类参考不超过 4 张，全部是真实可访问的已确认图，顺序与卡片声明一致
- [ ] **画幅与分辨率可用**：比例在 `1:1/16:9/9:16/4:3/3:4` 内，尺寸 1K/2K 与该画风的验收档一致

### 角色专项

- [ ] **四视图唯一版面**：一张 16:9、四栏齐全；第一栏是腰部以上正面半身像、面部结构清晰，其余为正面全身、侧面、背面；没有退化成三视图或单视图
- [ ] **比例尺不共用**：半身像头顶贴齐栏顶、裁到腰、单独放大，正面/侧面/背面三个全身栏按脚底线对齐、共用同一全身比例尺，不把半身像画成全身
- [ ] 与其他角色区分明显，不共享模板脸；两三个识别特征在半身像与正/侧/背三栏都成立
- [ ] 同发型、同体型、同一套衣服；钮扣、衣襟、纹样、口袋、腰带、鞋、配饰位置跨视图一致
- [ ] 未擅改年龄、体型、肤色与肤发识别点；表情与站姿自然

### 场景专项

- [ ] 布局可读且连续：出入口、通道、固定地标位置与卡片一致，能支持人物实际行走
- [ ] 前中后景层次与遮挡关系成立，不是靠虚化糊出来的纵深
- [ ] 主光可解释，时段/天气的连带影响正确（夜＝灯成为主光、雨＝地湿与玻璃挂水）
- [ ] 空镜确实无人，生活痕迹符合剧本，不额外暗示未发生的事件

### 道具专项

- [ ] 轮廓、结构、关键纹样可辨；材质与状态有因果，不出现互斥状态
- [ ] 无人手、无佩戴者、无使用动作；有可信的承载面与投影

### 记录与回写

- [ ] 选用结论与修订项写回 `assets/assetCards.md`，生成/验收状态写 `plan/story.mtrack`
- [ ] 没有新建或改写 `画布/资产.json`；没有把候选图当已采用图
- [ ] 失败项逐个记录，只重出失败项，不默认覆盖全部已确认图
