# 新剧本自动整理流程（V4）

## 唯一触发词

用户说 **“整理新剧本并更新知识库”**，即明确授权本轮执行以下操作：

- 读取已经配置的知识库根目录；
- 在该根目录内创建或使用 `90-隔离与待审/新加入待分类`；
- 只整理这个入口里的新文件；
- 在知识库根目录内部移动文件、建立必要子目录；
- 整理完成后复核当前知识库模式。MD 模式只承认可读 `.md`，更新同一个 `知识库索引.sqlite`；旧 SQLite 模式对 PDF、DOCX、TXT、MD 运行原增量索引。

该口令不是授权删除文件、覆盖同名文件、修改原始文档内容、移动整个知识库，或操作知识库以外的文件。

## 第一次或入口为空

1. 从当前平台的 `filmProject/knowledgeBase.json` 读取 `root`，不得套用作者电脑的盘符。
2. 尚未配置时，只让用户选择一次知识库根目录。
3. 创建 `90-隔离与待审/新加入待分类`。
4. 如果入口为空，在聊天中直接显示该学员电脑上的完整路径，并只说：

   “请把网盘下载的新剧本和编剧书放进这个文件夹，放好后再说：整理新剧本并更新知识库。”

5. 到此停止，不运行空索引，不要求学员自己判断分类。

## 发现新文件后

只扫描 `新加入待分类`，不得顺便重排已经整理好的旧知识库。

先读配置里的 `mode`。**MD 模式直接分类的只有正文可读的 `.md`**；PDF、DOCX、TXT 可以收件并判类别，但先留在 `90-隔离与待审/待转换为MD`，不得把搬进正式分类等同于“已能全文检索”。旧 SQLite 模式继续支持 PDF、DOCX、TXT、MD 增量索引；扫描版仍需 OCR。

发现 ZIP、RAR 或 7Z 时：

- 只有当前电脑具备可用解压工具时才处理；
- 解压前检查压缩包内部路径，拒绝写出知识库入口之外；
- 只保留 PDF、DOCX、TXT、MD 文档，不执行 EXE、BAT、CMD、PS1、JS、VBS 或其他程序；
- 加密、损坏或无法安全检查的压缩包保留原地并报告；
- 成功提取后把原压缩包移动到 `90-隔离与待审/已处理压缩包`，不得删除。

## 去重和分类

1. 先按文件哈希去重；重复文件移动到 `90-隔离与待审/重复文件`，不得删除。
2. 根据文件名和可读取正文判断内容，优先使用已有目录：
   - 传统神话、志怪、八仙、道教、历史制度、民俗和中国风研究：`01` 至 `04`；
   - 中日韩美高热类型片和中文爆款短剧：`05-中日韩美高热类型片`；
   - 有明确电影节、奖项或官方剧本证据：`06-全球电影节获奖剧本`；
   - 用户明确说明拥有或获得授权的完整剧本：`07-用户授权完整剧本`；
   - 编剧、导演、表演、摄影、剪辑、声音和影视方法书：`08-编剧方法书籍`。
   - 小说与文学故事正文：`10-小说库`，优先复用其中已有的可靠分类；不是因为书名像小说就移入，史料和研究仍按实际内容区分。
3. 不能从文件名或正文可靠判断的文件，移动到 `90-隔离与待审/待人工确认`；不得猜测热度、评分、国家、奖项或授权状态。
4. 同名但内容不同的文件不得覆盖，在文件名后增加短标识并在报告中说明。

## 更新可检索状态

分类完成后运行本技能 `scripts/update_knowledge_index.py`（或其 `.ps1` / `.command` 包装；脚本路径以技能实际安装位置为准，用 skillOperator list/read 定位，基准同 [13knowledgeBase.md](13knowledgeBase.md)）：

- MD 模式：新增、修改和删除同步到根目录同一个 `知识库索引.sqlite`，报告文档数、片段数、更新与跳过数；索引尚未更新时新正文可回退扫描。非 MD 文件报告为“待转换，尚不可检索”。旧运行时不支持建索引时选兼容 Python 重试或明确告知未更新，不能假报成功。
- 旧 SQLite 模式：只处理新增或改动文件，报告索引与 OCR 失败情况。

不得使用 `--include-isolated`。待人工确认、重复文件和已处理压缩包继续保持不入库。

## 聊天报告

完成后用人话报告：

- 本次发现多少个文件；
- 成功分类多少个；
- 重复多少个；
- 待人工确认多少个；
- 压缩包成功或失败多少个；
- MD 模式报告可读 MD 数与待转换数；旧 SQLite 模式报告增量索引新增、更新、未变化、失败和 OCR 数量；
- 实际知识库根目录与索引报告路径。

平台不能访问电脑文件、不能安全解压或不能执行 Python 时，明确说明当前平台不能自动整理，不得假装已经移动或入库。
