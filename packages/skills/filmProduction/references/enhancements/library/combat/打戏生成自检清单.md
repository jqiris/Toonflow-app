# 打斗生成自检（09-M）

本清单由 CINEDANCE 对已启用 09-H 至 09-L 的当前场次执行。检查结果写在提示词之外；缺关键证据时报告问题，改拍法先保存新草稿，不擅改作者剧本或确认镜头。

## 剧情与导演方案
- [ ] 参战角色、目标、武器、能力、地点和胜负符合当前确认稿；没有导入来源案例的人名、配色或武学绑定。
- [ ] 已确认镜头顺序、机位、运动和切点得到保留；新动作建议若改变它们，已形成差异草稿并取得作者确认。
- [ ] 作者没有要求的伤势、破坏、法术、对白或终结结果没有被额外加入。

## 动作与画面可读性
- [ ] 关键动作能说明起点、路线、闪避或接触、受力与结果；落空和防守不被写成无来源的命中。
- [ ] 支撑、距离、持物和路径可执行；景别能看见本镜必要的手脚、接触点或落地结果。
- [ ] 摄影机移动有起止和跟随目标，或固定有理由；没有为了套模板强制震镜、环绕、斜拍、居中或固定切镜次数。
- [ ] 重复动作具有试探、诱骗或递进作用；没有无信息重复，也没有因为出现过同一招就机械禁用。

## 空间、表演与参考素材
- [ ] 以场景地标、人物世界位置和摄影机一侧核对轴线；换机位造成的画面左右变化不被直接判为人物瞬移。
- [ ] 相邻任务的动作、持物、体力、衣物、光向和对白位置衔接，完整文字能独立理解。
- [ ] 素材按 09 的本场选择登记真实路径和职责；身份图、场景研究板与严格首帧不混用。检查清单不另加必须画箭头、必须制草图或必须使用某个图像编辑工具的条件。
- [ ] ACTING 的表演状态得到承接；没见到实际图片或视频时只检查计划，不宣称视觉验收通过。

## 时长与模型编译
- [ ] 内部镜头与生成任务分开计时；对白按 CINEDANCE 当前自然语速预算并计入呼吸、停顿和必要动作。
- [ ] 未强制 30 秒拆两条 15 秒，也未把场次拉长凑额度；组合与拆分符合作者拍法和实际模型入口。
- [ ] 不强制每段开头立刻接触、必须有肘击或必须打出终结；动作密度服从剧情与表演。
- [ ] 只有 CINEDANCE 按已选模型输出正式提示词，未混入旧 Skill 的输出模板、下载说明和内部检查过程。
