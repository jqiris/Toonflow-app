# 07-J 导演风格与色卡 / 跨阶段按需参考

本分支可在 01–09 任一阶段手动挂载，07-J 仅作稳定编号。当前专业阶段是唯一正式成果负责人，沿用总路由、剧本知识桥和资产登记规则。软件内置本页。导演原文、色板和图片留在用户另外挂载的资料文件夹。

## 使用入口

通过导演风格与色卡入口选择解压后的资料文件夹，挂载后搜索、分类、查看，再手动选用参考。挂载目录不等于启用正文。只读取用户所选资料片段并用于当前任务，不发送整库或原片。新增资料后更新目录。换电脑重新选择其本机目录。

## 当前阶段如何使用

- 有 workbench://director-style-selection 时，只读取这次选中的资料片段；没有时可按已有项目视觉设定创作，不强迫下载资料包或反复问模型。
- 先继承当前阶段已有的已确认剧本、角色与资产 ID、时代、服装、画幅及模型选择。按当前任务提取视觉方向、空间、光色、材质、构图或连续性方法。尚未确定的内容列为候选，不补造身份、人物关系或情节。
- 人物身份校准卡按 07 册 C 卡口径：2:3 四视图整版（半身格=唯一脸部权威源、正面全身格默认遮脸、侧面与背面承接结构）；环境光色不污染身份校准卡；场景和分镜图才承接场景氛围。
- 从参考中选一个明确构图与相容光线，不机械拼接全部关键词；不要把低角度和高角度、静帧和长镜头同时写进一张图。
- Nano Banana、GPT Image等对话图片通道用自然语言；只有目标协议支持时才输出MJ/SD参数。资料中的旧型号名、参数和“否定词无效”等判断不是能力事实。
- 色值和占比是资料作者整理的建议，并非软件核验的原片采样。只标注实际读取的导演名称和相对来源；不存在的剧照标为缺失，不补造来源或联网下载替代。
- 在 07 由 07assetsImages 册输出完整资产提示词并落 `assets/assetCards.md`。其他阶段交当前专业分册形成方法卡或候选表达。只在作者采用时按原流程更新正式依据，已有图片和锁定资产的修改产生候选。
- 08/09 也可手动选用新的导演资料，先与已采用的视觉设定核对，冲突只提出候选。资料中的固定人名、角色、场景和视频模板不自动成为本项目事实。挂载不自动切阶段、改剧本、改资产、生成图片或视频，也不新增整库读取、联网或模型权限。

## 不强迫整库安装

没有资料包时说明“可选导演参考尚未挂载”，提供入口即可，继续当前创作。不同项目各自保存所选导演；挂载路径和索引是本机配置，不进入分发包。
