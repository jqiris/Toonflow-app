# 专家模块登记表与冲突规则（V4）

内置分支沿用 `stage-menu.md` 和 `resource-map.json` 的稳定编号，按功能分类检索。编号前缀及适用阶段仅作内部元数据，不能限制手动挂载或自动切换阶段。全部内置与个人分支均可在 01–09 的任一阶段选择，包括 06 压力测试。

内置分支登记以下字段，个人分支可用作者提供的名称和资料路径登记到项目方法记忆，无需先申请内置编号。

`id或个人名称 / 中文名称 / 功能分类 / 适用阶段（内部元数据） / 作者选择与用途 / 所需事实依据 / 选中资料及章节 / 方法卡内容 / 当前阶段正式成果负责人 / 可组合项 / 冲突项 / 必须保留 / 可调整 / 生效范围 / 版本 / 来源与授权状态`

## 当前正式成果负责人

负责人由当前阶段确定，与挂载分支的编号无关。01 为 `01concept.md`，02 为 `02characters.md`，03 为 `03worldbuilding.md`，04 为 `04treatment.md`，05 为 `05screenplay.md`，06 为 `06stresstest.md`，07 为 `07assetsImages.md`，08 为 `08acting.md`，09 为 `09shotPlanning.md` + `10videoPrompts.md`。分支只交方法卡，不能另立总控或正式成果链。

00-A 至 00-G 是镜头语言工具，不新增第 00 阶段。旧标 `06-A` 至 `06-J`、`07-A` 至 `07-G`、`08-A` 至 `08-Q` 分别兼容现有 `07-A` 至 `07-J`、`08-A` 至 `08-G`、`09-A` 至 `09-Q`，只在项目版本或作者明确提供旧标证据时迁移，不凭当前阶段猜编号。

## 已有编号的增强职责
- 09-H 打斗动作与镜头增强使用 `modules/combat.md`，具体设计按已选用途读取 `modules/combat-execution.md` 和已选技法专项。跨阶段提取人物动作约束、攻防因果、节拍或风险，交当前阶段负责人。09 的正式动作与镜头设计归 CINEDANCE。不执行来源旧主 Skill 的独立编译、固定七角色、强制双 15 秒或固定拍法。保留作者剧本、能力、武器、场景、导演方案与实际模型能力，未确认细节只列候选。来源为学员原包 seedance-combat-prompt 2.2.0 经适配的方法，未取得飞驰新附件。
- 09-M 打斗自检只在作者选择时读取 `library/combat/打戏生成自检清单.md`，可与其他已选打斗分支组合，不随 09-H 至 09-L 自动启用。跨阶段输出当前任务的缺项与冲突方法卡，不新增出图工具、草图、箭头、招式次数和旧语速硬条件。当前确认稿与真实素材证据必须保留，修订先列候选。原版自检备份的来源状态保留。
- 07-B 主场景空间锁定与多角度图使用 `../../07assetsImages.md` 第八步，作者选择九宫格时再读 `../modules/reference-art-source.md`。跨阶段提供空间、地标、主光与动线约束方法卡。07 正式资产仍归 Lira。可与已选人物及空间方法组合，不得并列互相矛盾的场景几何。出图数量、角度、研究板或九宫格方式只作候选，保留剧本事实、已确认场景几何和世界光向。用户提供的资产库方法已按现有规则适配，外部包不作为第二总控。
- 09-B 叙事分镜与跨段接力使用 `../modules/narrative-storyboard-handoff.md`。跨阶段提取事件覆盖、起止状态、空间证据和接续风险，交当前阶段负责人。可与已选导演、调度和模型方法组合，不重排已确认导演方案，不独立编译提示词。保留剧本事件、原台词、已锁机位与切点，未锁节点只作表达候选。用户提供的分镜包已按现有规则适配，外部包不作为第二总控。

## 组合规则
- 任一阶段可以多选所有内置与个人分支。先合并为当前任务方法卡，再由当前阶段唯一负责人输出正式成果。不以编号、功能分类或适用阶段过滤目录。
- 00 镜头语言工具可跨阶段与其他已选分支组合，不单独弹阶段菜单。不写推荐标签，不自动评分、推送或附带启用其他分支。
- 07-A 与 07-B 可组合，但只能格式化已确认事实，不能发明新角色或剧情。07-B 的多角度是同一场景真实换机位，场景九宫格是轻量备选；两者不得各自建立互相矛盾的场景几何。
- 09-B 只加强叙事节点覆盖与跨段连续性，可与导演顾问及调度模块组合；09-A 已确认的镜头设计和 `film-cinedance` 的时长、模型编译规则不被 09-B 覆盖。
- 09-A 可与 09-B 至 09-P 组合：A 决定导演意图和镜头方案，其余只提供专项材料。
- 09-Q 可与 09-A 至 09-P 组合：Q 只把已确认方案编译为 Seedance 2.5，不得重新设计。
- 多选只表示方法可组合，不产生额外正文读取或生产授权。记录作者指定的阶段、场次或项目级生效范围，后续按该范围沿用，跨阶段不自动扩大选择。

## 冲突与降级
- 04-B、04-C、04-E 及其他分支均可在任一阶段手动选择，按本轮用途只读所选章节。涉及逐镜、模型或资产生产资料时提炼当前阶段所需方法，不自动产出下游正式文件。
- 同一条提示词不得混合 Seedance 2.5、Seedance 2.0 与 H3 格式；多版本必须分文件。
- 用户本轮明确要求、已确认项目事实与已锁导演方案优先于专项或通用方法。挂载本身不构成改稿或解锁授权，事实冲突先说明并交作者取舍。
- 缺必需输入时只报告最小缺项，不得用模型印象补造项目事实。
- “镜头语言重复风险”只作为镜头方案后的质量检查，不能替代事前逐镜设计。正式提示词前必须已有用户确认的景别、角度、构图、光线、运动或固定理由和剪切点。

## 按需读取与来源边界

查看目录只读登记信息。作者点选或点名后，只读取所选正文中本轮需要的章节，不启用全库，不沿引用链自动加载其他分支。目录挂载和分支选择都不新增联网、模型调用、生成、文件覆盖或本地知识库检索权限。

模板中的固定人名、人数、时代、关系、能力、事件、对白与场景只作来源示例，须逐项绑定本项目已确认依据。缺事实时说明缺项或草稿假设，不用模板填成项目事实。06 只补充诊断方法，不能自动修改剧本或资产。
