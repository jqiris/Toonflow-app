# 影视分支方法目录

按实际内容分组，所有分支均可在01–09任意阶段或自由模式手动挂载。编号是稳定标识，不表示所属阶段或使用限制。功能分类与适用环节见同目录resource-map.json。只加载所选正文，正式成果仍由当前阶段分册负责。

## 摄影与镜头

- 00-A 观众离人物多近 / Shot Size——用远景、中景、近景和特写控制情绪距离。
- 00-B 摄影机为什么要动 / Motivated Camera Movement——选择有剧情理由的推、拉、摇、移、跟或环绕。
- 00-C 人物在画面里怎么站 / Composition and Blocking——用构图、前后景和留白表现人物关系。
- 00-E 什么时候切镜 / Editing Points——选择动作匹配、遮挡、声音先行等合理剪切点。
- 00-F 特殊角度看世界 / Special Camera Angles——按需使用主观、俯拍、仰拍、贴地、虫视或鹰视。
- 00-G 复杂镜头怎么走 / Compound Camera Paths——写清复合运镜的起点、路径、跟随对象和终点。
- 07-E 构图与透视 / Composition and Perspective——规定前中后景、视线高度、空间纵深和主体位置。
- 09-A 导演顾问 / Director Consultant——先定镜头目的、机位、运镜和剪切理由，用户确认后 CINEDANCE 不得推翻。
- 09-E 特殊运镜 / Special Camera Moves——选择贴地、低空、俯冲或环绕等有剧情理由的运动。

## 光色与导演风格

- 00-D 光从哪里来 / Lighting Direction——锁定光向、反差和色温，让光线参与叙事并保持连续。
- 01-A 作者审美锚点与案例 / Authorial Style——记录本项目作者的色彩、节奏与禁忌；案例设定不直接带入本项目。
- 01-B 找适合的导演语言 / Directorial Language——按题材和情绪推荐视觉方向，只借方法，不照搬作品。
- 01-D 导演视觉方向速查 / Chinese Fantasy Animation——查阅不同导演的光色、构图与镜头倾向，不预设为国漫或仙侠。
- 07-F 灯光与材质 / Lighting and Materials——固定光源、反差、色温、表面材料和时间状态。
- 07-J 导演风格与本机色卡 / Local Visual References——挂载可选导演资料，按资产选用光色与构图；只读取选中资料，不把整库塞进上下文。

## 创作节奏与分析

- 04-A 每场戏该有多长 / Scene Duration Budget——按事件、对白和情绪节拍做场次时长预算。
- 04-B 这场戏到底要完成什么 / Scene Purpose——写清人物目标、冲突、关系变化和视觉任务，不提前拆镜。
- 04-D 场与场怎么接 / Scene Transitions——确定叙事连接点和转场条件，不直接写视频特效。
- 04-E 动作戏先讲清因果 / Action Causality——写清谁先动、局势怎样改变、结果是什么和需要多长时间。
- 04-F 拆一部参考片的方法 / Reference Film Analysis——只提取场次结构、节拍和推进方法，不复制剧情与对白。

## 人物身份与造型

- 02-A 古代宫廷人物 / Court Characters——让身份、礼制、服装和行为相互匹配。
- 02-B 古代市井职业 / Historical Occupations——用职业工具、生活痕迹和阶层习惯把角色写具体。
- 02-C 古风男性造型 / Historical Male Design——区分发型、冠饰、服装层级、身形和身份气质。
- 02-D 现代男性造型 / Modern Male Design——用职业、年龄、穿着、体态和生活状态拉开差异。
- 02-E 都市人物造型与穿搭 / Distinct Ensemble Characters——以发型、服装与穿搭区分都市人物，保留作者已定身份。
- 02-F 女性造型区分 / Distinct Female Design——把发型、妆面、服装、年龄和人物目标连起来。
- 02-G 战斗身份 / Combat Identity——锁定训练背景、武器、身体习惯和战斗限制。
- 07-A 角色身份参考图 / 2x2 Character Identity Card——按作者选定的版式与视图数量建立人物身份和服装参考，不固定2×2。

## 场景与空间

- 01-C 跨题材场景灵感 / Genre Blending——比较现实、幻想等题材的场景模板，按本项目设定提取空间灵感。
- 01-E 都市短剧场景参考 / Live-action Short Drama——查阅都市短剧常见地点及悬疑、拉扯、转折场景，服务当前剧情。
- 03-A 古风环境体系 / Historical Environments——统一建筑、道路、生活方式和空间层级。
- 03-B 都市环境体系 / Urban Environments——让地点符合人物阶层和剧情功能。
- 03-C 混合题材场景参考 / Hybrid Genre Locations——选取跨题材地点和环境模板，不据此新增世界能力规则。
- 03-F 场景俯视图与空间规划 / Combat Space——用平面布局、入口、通路与地标校对站位和行动空间。
- 04-C 人物怎么进出和站位 / Entrances and Blocking——规划入口、出口、区域和移动任务，为机位设计留空间。
- 07-B 主场景多角度图 / Multi-angle Scene Views——先锁入口、通路、地标和光向，再从真实不同机位出图；九宫格可选。
- 07-H 古风场景资产 / Historical Scene Assets——补足建筑结构、时代气质、生活物件和可拍机位。

## 世界与能力规则

- 03-D 法术属性规则 / Magic Rules——写清来源、表现、代价、克制和使用边界。
- 03-E 国漫大招体系 / Ultimate Move System——先定大招的剧情意义、前摇、代价和结果。

## 对白与声音

- 05-A 台词像人说话 / Natural Dialogue——删除解释性废话，补真实回应、停顿和话外之意。
- 05-B 每个人说话不一样 / Distinct Character Voices——根据身份、关系、欲望和防御方式区分角色语气。
- 08-C 台词能自然说完 / Natural Dialogue Timing——计算语速、呼吸、停顿和听者反应，不够就拆镜、延长或让作者删改。
- 08-D 配音怎么说 / Voice Direction——规定重音、气息、速度、情绪变化和口腔状态。
- 08-E 声音和配乐任务 / Sound and Music——区分环境声、动作声、对白、留白和音乐进入时机。

## 表演与动作

- 05-D 动作写得能拍 / Filmable Action——把“激烈打斗”写成有目标、攻防、环境和结果的可表演动作。
- 08-A 微表情和真实反应 / Micro-expressions and Reactions——把情绪写成眼神、呼吸、下颌、手部和反应延迟。
- 08-B 情绪变成可见行为 / Visible Emotional Behavior——把抽象情绪转成演员能执行的动作和节拍。
- 08-F 动作怎么表演 / Physical Action Performance——写清重心、惯性、受力、疼痛和动作后的身体状态。

## 连续性与一致性

- 05-C 前后不能穿帮 / Continuity Check——核对人物、场景、道具及前后镜头的状态连续性，贯通资产与镜头。
- 07-C 故事板一致性 / Storyboard Consistency——用小图检查人物、场景和动作顺序，不替代正式提示词。
- 09-B 叙事分镜与跨段接力 / Narrative Storyboarding and Handoffs——按剧情变化拆节点，锁定最后有效位置与真实收尾状态，不机械一句台词一镜。
- 09-C 多人站位连续性 / Blocking Continuity——锁定轴线、世界位置、画面位置、朝向和出入口。

## 白模与分镜预演

- 07-D 白模分镜与空间草图 / Whitebox and Spatial Sketches——用图像模型生成 AO 黏土白模、铅笔草图或站位图，先检查空间、遮挡和机位；Blender 仅为进阶替代。
- 09-D 故事分镜图设计 / Opening and Ending Frames——将已有故事事件转成可读的景别、机位、构图与连续分镜。

## 真人与画面质感

- 05-F 生活化真人质感 / Grounded Live-action Performance——按需要选用生活光、真实肌理与自然反应，适用于真人图像和视频。
- 07-G 电影级画面质感 / Photorealism——细化肌肤、五官、发丝、服装与环境材质，适配图像和视频。
- 08-G 真人表演校正 / Grounded Performance——加入真实停顿、犹豫、失误、视线和身体微动作。

## 打斗与特效

- 05-E 属性技能与特效表现 / Story-driven Powers——将作者已定能力转换成材质、光线、运动和环境反馈。
- 09-H 打斗动作与镜头增强 / Combat Action and Shot Enhancement——把攻防、受力、破招和镜头节奏写具体，按剧情安排时长与生成分组。
- 09-I 兵器怎么打 / Weapon Combat——按武器距离、握法、攻击线和回收动作设计镜头。
- 09-J 徒手怎么打 / Unarmed Combat——区分步法、重心、攻防距离、接触点和受击反馈。
- 09-K 战场怎么利用 / Battlefield Tactics——利用地形、障碍、队形、掩体和危险区推动局势。
- 09-L 特殊技能怎么接战斗 / Combat Skills——写清技能触发、范围、反制、代价和物理结果。
- 09-M 打斗自检 / Combat Quality Check——检查方向、距离、受力、连续性、胜负和不可执行动作。
- 09-N 大招完整五段链 / Five-stage Ultimate Move——拆成前摇、聚能、释放、对抗和结果的可生成镜头链。
- 09-O 属性招式专项 / Elemental Moves——按属性规律设计运动、材质、光线、命中和环境反应。
- 09-P 国漫级奇观设计 / Chinese Animation Spectacle——用空间层级、力量尺度和节奏升级奇观，不改变剧情胜负。

## 视频生成与返修

- 07-I 静图能否直接微动 / Still-image Motion Readiness——预查头发、衣摆、景深、遮挡和动作空间，减少废片。
- 09-F 静图微动视频 / Subtle Still-image Animation——限制运动幅度，保护人物身份和构图，避免画面融化。
- 09-G 生成废片返修 / Generation Troubleshooting——先定位资产、表演、连续性、镜头或模型语法问题，只修故障点。
- 09-Q Seedance 2.5 精细适配 / Seedance 2.5 Detailed Adaptation——把已确认镜头编译成最长 30 秒、多参考和分时段控制提示词，不负责重新改镜头。
