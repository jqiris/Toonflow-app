# 角色与场景参考图

## 使用条件

作者在任一阶段手动选中或点名参考图方法时使用，编号不限制挂载。向当前专业阶段提供身份、空间、美术与一致性方法卡。正式图像资产由 07 Lira 负责，挂载本身不切阶段、不改剧本或资产，也不授权生图或白模执行。

## 核心原则

1. 以当前已有的最新确认角色卡、世界观、剧本场次和资产版本为据，尚未形成的依据列为缺项，不用模板人名、固定人数、服装或场景功能补成项目事实。
2. 角色四面板优先锁定：正面、侧面、背面、表情/状态；背景中性，人物比例一致。
3. 07-B 默认按 `../../07assetsImages.md` 第八步先锁同一场景的空间与固定地标，再从真实机位输出多角度；场景九宫格是结构简单或用户点名时的备选，仍须保持入口、地标、主光和时段一致。
4. 参考图只锁身份和美术，不自动等于某个视频镜头的构图。确需锁定本镜头开头画面时，按已确认的新机位单独生成或编辑首帧；只用场景参考图或文字时，不冒称已有首帧。
5. 工作稿中的箭头、红圈、站位 X、网格、镜号和文字标注不得出现在成品图。

## 两种标准任务卡

- 角色身份卡：使用 2×2 四宫格，分别锁定正面脸、侧面脸、正面全身和背面全身；四格必须是同一角色、同一服装、同一配色和同一身份状态。它负责锁人物，不代表某个视频镜头的构图。
- 场景任务卡：默认输出空间底图、场景母版和真实换机位的多角度提示词；九宫格仅为轻量备选。至少锁定空间入口、主要地标、主光方向、材质、时段和可用机位方向。它负责锁地点，不替代后续镜头首帧。
- 作者选定详细版式资料时，才定向读取 `reference-art-source.md` 所需章节。任一阶段均可用作方法参考，不自动加载全库或生产资产。

## 方法卡输出

- 资产类型与用途
- 必须保留的角色/场景事实
- 图片布局和一致性锁定项
- 成品中必须移除的标注元素
- 需要用户补充的最小资产
