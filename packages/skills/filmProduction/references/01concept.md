# 01 概念锚定

**做**：判定位 → 出故事大纲 → 五问自检 → 落版本卡。**不做**：角色圣经、世界观、拆场、台词、任何下游产物。

## 第一步：定位菜单（未明确时逐字发送并停止，不改写成其他问卷）

用户已明确（"E""按快速出片"）直接继承，不重复问：

```text
请问您的项目定位是什么？请回复 A、B、C、D 或 E（支持多选组合与补充说明）：
- 【A】院线长片/经典剧集（经典三幕式长篇结构）
- 【B】电影节/艺术短片（电影学院三层结构法）
- 【C】流媒体/爆款网剧（强爽感引擎组合）
- 【D】高阶自定义版（保留作者自己的作品形态与写法）
- 【E】快速出片（商业短剧快写：先定全剧故事，再分集、写首批剧本，后续仍走资产到视频制作）
```

**第二步子菜单（不可跳过自编）**：选 A 直接进第三步；选 B 只问一次"你希望观众看完有什么感受？有喜欢的影片也可以说；不知道就回'默认'，我给你两个不同讲法"；选 C 只问一次"你已有题材或人物吗？没有就回'默认'，我给你推荐两种类型引擎"（不得自动塞系统、重生、战神设定）；选 D 请作者直接描述体量、风格、要保留的设定；选 E 一次合并补问真正缺的：发行地区/语言、题材、受众、付费/免费、总集数、单集时长（不确定标"暂定"，不重复让用户选 C）。

**第三步**：先讲清有起因、人物行动或观察、后果与结局的**故事**，再按路线组织展示。B 的故事不先被隐喻框住；C/E 的爽点从人物因果长出，不用固定三步链代替故事。

## 路径 A · 长片/经典模板（完整填充，不折叠合并）

1. **一句话故事**：「【类型】的【主角】在【背景】中，遭遇了【核心冲突】，必须采取【关键行动】，而这背后的代价是【X】。」
2. **核心主旨**（麦基）：「当主角做了【Y】，因为【Z】，生活变成了【X】。」
3. **题材与基调**：主要类型/子类型/基调（剧情·惊悚·动作·喜剧·黑色电影·悲剧·混合）/参考影片 3–5 部
4. **时长与体量**：目标时长/发布目标/项目类型（片长只用于估算，不决定 06 方法）
5. **主角**：名字；年龄/角色定位；致命缺陷（Hamartia）；渴望（外在显性）；需求（内在隐蔽）；弧光（从【X】到【Y】）
6. **反派**：名字/实体；动机；TA 有而主角没有的东西；与主角的镜像映射
7. **诱发事件**：在前四分之一（22%–25%）打破主角平衡的事件
8. **危机抉择**：两种互不相容价值观之间的选择
9. **高潮**：回应抉择的具体行动，全片最具物理动作性的点
10. **结局**：高潮后的新世界坐标，1–2 句
11. **主题与副主题**：核心主题一词/短语；副主题；差异化（同类题材中独特在哪）
12. **伏笔物件**：至少 3 件，每件写"场景 X 埋、场景 Y 炸"（第一幕铺垫、第三幕开火）
13. 参考场景（可选）：定基调/节奏/视觉的其他影片场景

## 路径 B · 电影节/艺术短片模板

1. **先讲完整故事**：人物处于什么具体处境；什么事件、关系或观察改变了局面；他怎样行动、拒绝、等待或见证；结尾人物、关系、处境或观众理解发生了什么变化。可以强冲突也可以静观；**不得为了显得文艺删掉作者的戏**。
2. **人物与观看问题**：谁在这件事里付代价？观众最初相信什么，结束时怎样理解？见证者主角不强迫写成目标型英雄。
3. **对白与声音**：有对白就让说话方式、信息隐瞒、关系争夺、潜台词推动戏；长对白可以成立；沉默、环境声、动作可承担叙事但不自动替代台词。
4. **作者表达与形式**：议题、观看距离、空间与声音如何服务故事；隐喻/母题/象征物只在确实增强观看时加入，**不给每部影展片强行配一个"视觉隐喻"**。
5. **交接记录**：人物关系与变化、关键事件或观察节点、结局事实、作者要求保留的对白或静默；格式仍是专业剧本不是散文梗概。

## 路径 C · 流媒体/爆款网剧模板

先交完整因果主线和结局，再按作者确认的题材选引擎，**不把金手指、羞辱、打脸当成每部剧的强制事件**。记录：主角主动策略、真实对手、底牌的限制与代价、阶段性兑现、关系副线、反派递进、集间问题、中段质变。付费剧规划卡前承诺与卡后兑现；免费剧只做留存，不伪造付费墙。作者要少问快写才转 E；**不得自行把已选 C 改成 E**。

### C/E 类型发动机（商业短剧专用）

- **底牌/金手指**可以是能力、身份、资源、知识差、证据、专业技能、关系网。超自然能力必须受 03 规则与代价约束；现实题材不凭空开系统。底牌首次使用要解决具体难题**同时暴露新的代价或敌意**。
- **打脸**=有人做过可见的错误判断，主角用行动或证据改变局面；反应来自人物利益；不得连续换人重复同一套羞辱。
- **反派按阶段施压**：每个对手有资源、欲望和阶段性胜利；小目标兑现后更高层阻力从既有因果出现，不靠反派集体降智。
- **关系副线**改变主角的选择成本，不是打脸间隙的装饰；每次关系推进在后续剧情留下影响。
- 男女频/地区标签只提示受众预期，不代替真实人物与文化语境；地方制度、职业事实未知即标待核实。

### E 两层结构

- 全剧五种任务：开局承诺、初次兑现、扩局、中段质变、终局兑现（功能划分，不预设固定集数比例；长连载分小弧，短集数可合并）。
- 每集六记：本集人物目标｜当下阻力｜主动策略｜实质变化｜对上集承诺的兑现｜留给下集的问题。集型在反击/蓄压/身份揭示/关系变化/对手反扑/关键选择/终局兑现间轮换，不规定"每集必须打脸"。
- 开场尽快交出人物处境与异常，不机械规定三秒羞辱或十五秒危机；单集尾部悬念必须来自本集真实行动或新信息，下一集有可见兑现，不反复骗"马上揭晓"。
- 免费只做集末留存与承诺兑现；付费才规划转付费位置和付后兑现，卡点取决于实际集数与平台，不按固定第几集硬套；卡前问题要值得追，卡后第一集必须解决或实质推进。
- 重复检查：连续相同施压/同类翻盘/换皮反派时，优先更换主角策略、损失、信息差或关系后果，而不是加音效与更大排场。

## 路径 D · 自定义

在用户指定的 A/B/C 底子上改，其余字段照该底子输出；使用场景跨风格世界（现实×回忆异风、穿越古今）时，把各分区完整风格句写进后续各卡正文，风格分区细则见 07/11 册。

## 第四步：五问自检（必做，写在正文后）

按作品形态逐条回答，不适用说明替代判据，不为填表虚构事件；艺术片/散文电影/见证者主角按位置、关系或观众理解的变化评估：

1. 人物追求、回避或见证的事情清楚吗？渴望与需求不同时能否形成张力；相同时不自动判失败。
2. 结尾与开头相比，人物、关系、处境或观众理解有什么可辨差别？
3. 反派（或核心外部/内部阻力）能一句话说出它要什么或挡住什么吗？
4. 已决定使用的伏笔、证据或物件，有可回看的建立与后续作用吗？不使用时不强造三件。
5. 这个故事一句话讲给朋友听，他会想接着问吗？

顶部元信息：定位（A/B/C/D/E）、目标时长、发布目标（注明时长仅供估算）、状态=待人工确认、版本 vNNN、依据（本轮实际输入）。落 `filmProject/concept/synopsis-vNNN.md` 后末尾附：

```text
【版本卡 · 01 概念锚定 · vNNN】
状态：草稿待确认（用户确认后改 已确认-当前）

分场阶段必读：核心主旨 … ｜ 结局方向 …
```

然后**停下等确认**；未确认不进 02。

## 红线

1. 不跳过定位菜单。2. 不替作者定主角**外在目标**——只能列候选。3. 不在这一步拆场、写台词；E 不把全剧架构称为已写好的剧本。4. "改一下"=留旧版出 v002，绝不覆盖。
