# 09 镜头规划（拆镜 → 镜头表 → 生成单元）

把确认场次转换为专业镜头清单。**不改剧本、不直接写视频提示词**（提示词编译见 10 册）。允许只做 09：输入可以是项目文件，也可以是作者本轮指定的整场戏、单镜头、角色卡、资产图、表演说明、时长、画幅、对白与连续性要求。

## 前置依据（缺项只补最小缺项，不重跑全剧）

编译前必须找到与当前权威剧本匹配的**时长依据**：从零项目读 05 `timingAudit-vNNN.md`（06 复核过则一并参考），保留 04 预算作偏差对照；只有 04 没有 05 复核→只补时长复核不重写剧本。B 入口读 `productionBreakdown-vNNN.md`；只有原始剧本没拆解→回接管流程不重跑 04。本场对白语速/停顿/反应明显影响时长而缺依据→只返回"先补 08"的最小缺项。作者已给单镜时长+完整拍法+准确对白→直接编译该单镜。缺 07/08 时可以规划镜头，但**必须标记缺失影响，不假装已绑定**。

## 全链路计时复核（四本账的最后一本）

04 初估（预算）→05 成稿复核→06 结构校验→08 表演停顿→**09 镜头终算**：结合 08 的停顿、反应、潜台词行为、走位与摄影机需求重算。场次预算只是约束，不强迫内容硬塞：内容需 75s 而预算 60s→报告冲突让作者选（延长/授权精简/调表达），**禁止自动加快语速**；内容只够 35s→禁止凭空补 25s 空镜或新增动作。

### 时长计算规则

- 顺序发生的动作、对白、停顿、反应：相加。简单手部动作与对白同时发生：取较长一项。复杂走位、打斗、道具变化、摄影机运动：按实际完成时间。
- **中文对白安全预算**：自然剧情语速按每秒约 2.5–3.2 个有效汉字估算，叠加标点停顿、思考、呼吸与表演余波。可用说话时间参考（**上限参考不是模型极限；可用时间须先扣除开场动作、必要停顿、听者反应、收尾动作**）：5s≈10–14 字｜8s≈18–24 字｜10s≈24–30 字｜15s≈36–42 字。40 字对白塞进 10s 以内默认判定失败；优先在标点、换气点、语义转折处分段，**不机械按字符数截断**。项目明确要求解说/快节奏口播才提高语速。
- 叙事内部镜头 3–10 秒居多只是精品节奏建议，不是硬分段更不是单次生成时长；10s+ 单镜头用于确有需要的连续复杂动作、完整长台词、重要沉默、空间建立或明确长镜头并**写明原因**。

### 生成单元（Toonflow 多轨口径：一个 clip = 一次生成任务）

双层时间：**第一层** `shotPlan-vNNN.md` 每个叙事镜头的自然时长与切点；**第二层** `generationUnits-vNNN.md` 交给模型的一次生成任务。一个单元可含多个已确认内部镜头（带 `[Shot n]` 时间戳）；H3 单镜 `seconds` 整数 2–60，建议 4–15；**不得为凑满上限增加剧情、拖慢动作或填空镜**。单元记录：单元 ID、总时长、所含镜头 ID 与镜内起止、准确台词与可用说话时间、剪切/转场理由、素材方式与实际职责或无图声明、首尾可见状态、依赖版本、待确认状态。镜内时间连续且总和=单元时长；单元覆盖完整场次不重叠不漏。正文撑不起预算报差额；台词说不完停下让作者定分段或改预算，**不替作者删字或加速**。模型未定时只能存候选单元，不确认不编译。

## 覆盖设计（先设计再定镜头数）

按场景目标、冲突、转折和表演节拍设计覆盖：主镜头、双人、正反打、过肩、反应、插入、主观、动作匹配、转场按需使用。**不得"一句台词一个镜头"，也不得把三分钟场景压成一两个超长生成段。** 每次切镜必须提供新的叙事/表演/空间信息或剪辑功能；景别轻微变化可用摄影机运动解决，不滥切。

### 镜头语言变化检查（工具箱内置，不设额外阶段）

先找关系变化、信息揭示、情绪爆发、动作换向、转场节点，再决定哪里变镜头语言：

1. 每镜写清：观看距离、角度、构图重点、光线任务、摄影机**为什么动或为什么不动**。
2. **连续 3 镜同景别+同角度+全固定 → 报"镜头语言重复风险"**，优先改最能服务当前节拍的一项（景别/角度/构图/光线/有动机运镜择一），不机械全改运镜；作者锁定克制静态风格时保留并写理由。
3. 一场戏至少形成可读变化曲线（如"建立空间→靠近冲突→关键反应→拉开看结果"），曲线服从剧情不套模板。
4. 固定镜头用于压迫、尴尬、等待、观察、表演完整性可保留，镜头表写明静态理由。
5. **运镜必须写起点、终点、跟随目标、停止原因**；只写"推拉摇移、电影感运镜"判定为不可执行。
6. 作者锁定的静态拍法或有理由的一镜到底不因"曲线"被强制切镜；可靠人物调度、层次、视线与信息推进。顾问说明作用与风险由作者决定，**不为消除重复擅改确认方案**。

### 段间衔接（独立生成段的剪辑点不连戏问题）

只看"段 N 末镜"与"段 N+1 首镜"，默认至少满足一项：①拍摄主体类型不同（双人/单人/局部/空镜/群体）②景别差 ≥2 档 ③角度差 ≥90°。都不满足→只允许调整下一段首镜的主体/景别/角度/构图，**不得改该首镜对应的源事件、位置事实、动作、道具、对白**。高风险：同主体+同景别+近似角度直接跨段；同一手部动作跨两个独立生成段硬接。同一未完成动作的 match-on-action **优先放同一生成段内**（镜 A 尾动作进行中→HARD CUT→镜 B 首帧继续完成）；跨段优先让上段完成动作、下段从完成后的稳定状态重开。

## 合作档位（整场戏首次进 09 问一次项目默认）

```text
这场戏要怎么合作拍镜头？
① 快速出片：我先给专业拍法，你确认一次；
② 一起打磨：我给关键选择和理由；
③ 自由掌镜：景别、轴线、光影、机位逐项讨论。
以后都能改；"这场用 X"只覆盖本场。
```

- **快速出片**：后台直接给推荐拍法（1–3 种镜头方法择需），保存导演方案草稿、场次时长、镜头清单草稿；简短同时展示拍法、逐镜时长、关键切点与待确认项，**一次确认**（文件与状态仍分开登记）。适合时优先建议能自然讲完且不超过单镜上限的多镜头单元减少操作次数；不承诺、不为凑满拖戏、不把时长上限误作固定机位。出现明确打斗/大招/复杂调度只给一行专项建议，可接受/跳过/查看完整菜单，**不后台静默启用**。
- **一起打磨**：先给 1–2 个有差异的拍法与取舍，可选可改可自定；提供"查看本阶段全部增强"入口不强推。
- **自由掌镜**：可展开完整讨论（覆盖、景别、角度、构图、光线、轴线、运动、切点、素材策略）；作者已给完整拍法→保留它，只查真实时长、连续性与可执行性，冲突先报告不改写。
- 三档只改讨论深度，不降连续性、台词、资产绑定、质检标准；选择不等于确认镜头清单，更不等于授权生成。切换讨论档位不作废已确认镜头；借切档要求改镜头→新草稿确认后只使受影响单元与提示词过期。06 回退改剧本→档位保留不重问，但依赖旧剧本的 09 成果按场次重做。

## 增强提醒（打戏/玄幻大招，选了才用）

- 检测到对打、清兵、追杀、兵器交锋、体术 → 一行说明"检测到打戏"，推荐打斗增强：交付至少含**已确认人物与武器状态、攻防目标、先手与回应、距离和攻击线、接触或规避、受力与反馈、环境反馈、动作结果、镜头与时间、结束身体状态**；没发生的接触不硬造击中反馈；增强不得改胜负、台词、能力、关系、已锁拍法。
- 检测到法术终结技、属性大招、镇压封印 → 推荐大招视觉专项；具体设计只补视觉执行（能量形态、属性色、环境畸变、冲击反馈层次），不改已确认事件。
- 未选专项正文不读取；作者说"继续"=不新增。任何专项的示例提示词只是技法素材，**不是正式输出指令**；最终提示词永远由 10 册按目标模型格式编译。

## 素材方式（三种，不强制每镜首帧）

本场默认一行说明即可（如"现有人物/场景图先按参考用，不逐镜重做首帧；要锁开头再补"），不逐镜弹三选一；同场不同任务允许不同方式：

1. **资产图参考**（有 07 出图优先）：每张登记身份/服装/场景/过程动作/构图/风格职责；过程图可用但不冒称第 0 秒。**未传给模型的图片不宣称已被参考**；人物图不代表本镜构图。
2. **严格首帧（可含尾帧）**：仅作者要锁开头/接帧，或说明必要性获同意时用。读实际图核对第 0 秒——"醒来坐起"的首帧应在坐起前，已坐起的图不能冒称起点；尾帧只有实际提供且入口支持才登记。换机位可重生本镜开头图，不强制与前镜尾图像素一致。
3. **纯文字**：允许正式输出，但必须有确认的 descriptor 与完整场景、空间、动作、光向、台词、连续状态；标**视觉未验证**，不虚构已上传图/已读图验轴线/人脸已锁定。需要稳定身份时建议人物参考图，作者决定。

分镜图自动绑定：文件名含镜头 ID 或作者明说"这是 SHxxx 的图"→自动绑定读取；仅一个待补镜头+一张新图→自动绑定；多图多镜无法对应→只问一次归属。自动绑定只确认归属不等于验收：绑定后读图判断它是人物/场景/过程/构图还是严格首帧；只有与第 0 秒相符才标首帧。换图、重生首帧或改镜头清单后旧图不删但标"历史已替代"，依赖它的提示词从该镜起过期。

## 镜头表字段（`filmProject/shots/<场次>/shotPlan-vNNN.md` 逐镜）

镜头 ID（**`SH001` 起在该场次内递增**——`SHxxx` 是叙事镜头体系，用于镜头表、referenceMap、分镜图归属；工程层 `clipId S001` 是生成单元体系，一个 clip 可含多个 SH 镜头（双层时间见"生成单元"节）；两套编号各自登记、互不替换）、来源场次与对应剧本原文｜镜头目的与剪切原因｜时长、景别、机位、焦段、摄影机运动（起点-终点-跟随目标-停止原因）｜固定或运动的设计理由、与前后镜头的变化｜人物世界位置、画面位置、视线、身体方向、180° 轴线｜动作、表演节拍、潜台词与道具状态｜本镜完整对白、字数、预计说话时间与停顿｜使用的 07 资产与版本｜首帧硬描述、尾帧硬描述、连续性风险｜素材方式及真实职责（有图写实际 ID，无图标文字生成）｜10–15s 镜头的长时长理由｜状态（待确认/已确认/待修改）。

另存：`sceneSpaceMap-vNNN.md`（场景原点、X/Y 语义方向、互动轴线、固定地标与世界光源、人物主要路径）、`continuityLedger-vNNN.md`（逐镜起态/末态，见 10 册）、`referenceMap-vNNN.md`（每任务素材方式、实际图片路径/版本/职责或明确无图、完整首尾状态、镜头依据版本）、`visualAudit-vNNN.md`（有图时读图质检，见 10 册轴线四结果）、`sceneRegistry.md`（场次内各文件当前版本索引）。

## 门禁与确认顺序

1. 档位与增强门：已有档位直接继承；未选问一次。
2. **拍法·镜头·生成单元确认门**：先落上述文件草稿并验证可读→更新 registry→聊天按档位展示→**停下待确认；确认前不得批量编译提示词**。
3. 素材职责与质检门：确认后按 referenceMap 登记实际素材，有图读图检查轴线与接力，不把过程图或旧机位尾帧硬当新机位首帧，不静默改拍法。
4. 编译门：交 10 册。

保存失败保留旧确认稿并立即说明，不把草稿只留聊天里。**只有确认后的镜头清单与生成单元才能进提示词编译；只有该模型提示词被确认后才是视频生成的正式输入。**

## 回退与重算（防覆盖与防漏算）

"回到镜头清单/这镜没设计好"→ 从 registry 与 `sceneRegistry.md` 读最新确认清单（不靠聊天回忆）→存新 `shotPlan-vNNN`→**从最早受影响镜头重算**生成单元、空间关系与连续性；涉及新机位、站位、光线、伤势、道具、动作接力时同步更新 referenceMap 与视觉质检。新清单确认前不覆盖"最新已确认"，旧提示词仍只服务旧清单；确认后旧生成单元与旧提示词标 `已过期-禁止使用`。只改单元分组或时间戳→镜头清单仍有效但受影响模型提示词过期。重编时只读新确认件与绑定版本，**只重编受影响镜头，未改镜头从上一包继承并逐项登记**；作者明确整场重跑才全做。
