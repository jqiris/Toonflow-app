# 跨镜一致性（同场景多角度）

跨镜制作要保证同一场景、角色、道具在不同镜头可辨认为同一事物。角色与道具沿用资产画布已确认版本并按 [canvasOperations.md](canvasOperations.md) 跨画布复用，不为单镜重新生成身份；场景的空间一致性按下表分流。

## 分流规则

| 本集需求 | 采用路径 |
|---|---|
| 场景单次出现或机位基本不变 | 直接引用资产画布采用版场景图，不新增派生 |
| 同一场景换角度拍摄（正反打、对向机位、反向视角） | 全景派生：基础场景图 → 全景图 → 各角度场景图，作该镜场景参考 |
| 复杂场景剧情：人物走位调度、连续多机位、跨镜空间关系 | 3D 预演（导演台），见 [preVisualization.md](preVisualization.md) |

两条路径可组合：导演台导出关键帧与全景派生角度图都能作分镜图或视频的场景参考；成本从低到高为直接引用、全景派生、导演台，拿不准时向用户说明差异后确认。

## 全景派生流程

1. 在本集画布为需要换角度的场景建立一条派生链：采用版基础场景图 → 全景图节点 → 目标角度场景图节点。每一环绑定真实图片输入，记录链路与所用父图版本。
2. 全景图以基础场景图为唯一场景输入：保持同一地点、空间布局、陈设位置与世界光源，扩展为覆盖场景全貌的广角/全景视图；不改变地点特征，不新增建筑结构。
3. 角度场景图从全景图得到：首选宿主全景链路工具——对图片节点调用 node:createPanorama(mode) 生成全景图节点，再 node:generateImage 启动生成，生成完成后 node:capturePanorama(count, layout) 按机位截取并自动连线为图片节点；无此能力或失败时降级为 ffmpeg 正射截取或导演台。降级或无链路能力时以全景图为参考输入，提示词写清机位方向、取景范围与保持项，生成后逐项核对结构、陈设与光源同场同景。仍无编辑/裁剪能力、参考派生又明显漂移时，如实报告并回退导演台路径或与用户商定替代，不用纯文本重画场景冒充派生结果。
4. 全景图与角度场景图默认是本集制作中间件（与分镜图同级），不写入资产画布正式库；用户明确要求沉淀为跨集复用的场景变体时，走衍生资产流程确认后入资产画布。
5. 分镜图（步骤 12）与视频（步骤 13）按镜号选用对应角度场景图作场景参考；参考顺序、回读与连接按 [canvasOperations.md](canvasOperations.md) 核对，同场前后镜重叠区域目视核对连续。

## 验收与失败

- 角度图与基础场景图明显不同景（布局、光源、材质漂移）判不合格：只重派生该角度，不放宽标准直接进入下游。
- 派生能力缺失或反复失败时记录具体缺项与影响镜头，改走导演台预演或请用户选择替代；不受影响的镜头继续推进。
- 本集阶段记录写明一致性结论：场景 → 全景图节点与路径 → 各角度图 → 使用镜头清单；未实际查看图片前不声称一致。
