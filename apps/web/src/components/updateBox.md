### 新增

- Agent 新增消息排队与任务引导：生成过程中可将纯文字消息加入队列，排队消息可取回编辑、删除，也可点击消息旁的「引导」按钮转为当前任务的引导；引导消息会在对话中单独标记。附件与提及需等待当前回复结束，上下文压缩期间暂不可排队或引导。
- Agent 新增本地队友通信，同一主会话下的主 Agent 与子 Agent 可查找队友并发送消息，运行中的队友可接收补充信息，空闲队友可继续原会话处理；暂不包含已安装团队的内部成员或远端 A2A。
- Agent 新增代码沙盒，可在受限环境运行 Bash 命令、JavaScript 和 Python，按需导入文件并将成功执行的结果保存回工作区；不支持联网、完整 Node.js、pip 或本机程序。
- Agent 的工作区文件工具新增文件查找和文本、正则搜索，支持查看匹配行号；该工具开启只读模式后仍可搜索。
- 新增 Agent 系统通知，窗口未激活时可提醒回复完成或工具等待确认，支持在通用设置中关闭；浏览器端需在 HTTPS 或 localhost 等安全环境中使用，并支持系统通知、获得授权。
- 设置新增网络代理，支持直连、系统代理和自定义 HTTP/HTTPS 代理，提供账号认证与连接测试，保存后用于服务端 AI、媒体等 HTTP(S) 请求。系统代理读取服务端所在设备的配置，暂不支持 PAC 自动配置；应用内代理设置需服务端使用 Bun。
- 首页项目卡片新增 ZIP 打包导出，便于备份和分享；当前项目文件总大小及导出包均不能超过 1 GB，最多包含 10000 个文件和目录。
- 图片、视频、音频生成及 3D 导演节点的提示词支持输入 @ 搜索并选择引用，按图片、视频、音频、文本分类；选择当前画布中的兼容内容会自动连线，也可从全局素材库导入内容、创建节点并插入引用。
- 画布中的内置内容节点支持拖拽右下角调整大小，聚焦缩放按钮后可使用方向键微调；同步优化媒体、文本及 3D 预览在调整尺寸后的布局。
- 分组新增背景配色，支持预设颜色、自定义颜色和透明度，也可同时调整多个选中分组。
- 独立运行的正式桌面客户端新增自动更新开关，默认自动检查并后台下载可用更新，安装仍需用户确认；可在「关于」中关闭，已开始的下载会继续完成。
- 桌面客户端新增退出确认，关闭窗口、退出应用或重启更新前提醒正在运行的任务将中断，可取消退出。
- 开发者设置新增平台模拟，可预览浏览器、Windows 桌面、macOS 桌面和移动端界面；切换会重新加载页面，原生能力与服务端权限仍以实际环境为准。

### 优化

- 补充设备互联、个性化设置、素材与文档操作、Agent 提及与预览、语音输入、快捷键和模型选择的多语言提示与无障碍标签。
- 完善 Agent 历史错误、模型配置、余额查询、MCP 连接与扩展包导入、插件安装、项目克隆和桌面更新的多语言反馈，并调整失败提示，方便判断原因及后续操作。
- 图片、视频和音频生成节点支持供应商声明的模型专属参数，切换模型时自动更新参数表单。
- 完善 TF-Router、APIMart、秘塔和优云智算部分视频模型的提示词引用适配，按实际提交的图片、视频、音频及首尾帧匹配参考编号，补充引用失效、内容为空及素材与生成模式不匹配的提示。
- 秘塔版 MiniMax-H3 新增 16 至 30 秒的视频时长选项。
- 节点视频播放器新增全屏按钮，需浏览器或 WebView 支持；优化小尺寸节点下的播放控件布局，音频引用显示对应图标与来源名称。
- 首页作品视频播放器的菜单与提示跟随界面语言，切换语言时保留同一视频的播放进度、倍速和音量。
- 文本节点的富文本编辑工具栏改用分组图标，显示当前格式的选中状态，并根据编辑历史启用撤销和重做。
- 优化首页卡片的半透明显示，并保持背景点阵在不同窗口尺寸下的颗粒大小和间距一致。
- 优化默认画布选择：根目录无画布时查找子目录，未找到时创建默认画布；增加删除保护，阻止通过应用删除项目中的最后一个画布。
- 改进 Agent 在请求准备、生成、重试和上下文压缩时的取消处理，并向工具与子任务传递停止信号。
- 停止 Agent 回复时，将已接收但尚未处理的排队与引导文字保存到对话历史，方便重新打开会话后查看。
- 优化子 Agent 继续协作时的结果与用量统计；重试等待期间收到引导或队友消息时可继续处理新信息，减少等待。
- 优化模型及附件请求的连接处理；Agent 自动重试开始新回复后，隐藏被替代的失败片段，减少重复显示。
- 补充部分模型的上下文与输出上限，改进已收录型号的供应商前缀、日期版本及常见别名识别。
- 优化对话流式滚动和切回会话后的高度恢复，并缓存已加载的工作区 Markdown 图片尺寸，减少重新显示时的跳动。
- 插件市场按最近安装或更新时间排列已安装插件，方便查找新安装或更新的内容。
- 优化 FFmpeg 检测和媒体处理的执行稳定性，完善任务取消及错误反馈。
- 浏览器工具未指定程序路径时，启动失败会继续尝试其他检测到的 Chrome、Chromium 或 Edge。

### 修复

- 修复尚未打开画布时，Agent 消息因画布标识为空而被拒绝的问题。
- 修复使用中文等输入法选字时，按 Enter 可能误发送 Agent 消息的问题。
- 修复复制、粘贴一组节点后，普通提示词中的引用及引用顺序未同步关联到同批复制的新节点的问题。
- 修复 APIMart Wan 和优云智算 Seedance 部分单图模式未正确提交参考图的问题。
- 修复 APIMart Seedance 参考图片审核顺序与生成引用不一致的问题，改为逐图审核并保留原顺序，审核失败时停止生成。
- 修复节点菜单键盘导航带动页面滚动的问题，优化菜单边缘定位与画布滚轮缩放。
- 调整移动客户端的页面缩放，避免聚焦输入框后页面意外放大；画布缩放仍可使用。
- 修复 Windows 缺少系统 tar 时无法安装或更新的问题，增加自动下载并校验官方 7-Zip 后备工具的支持；首次下载后备工具需要联网。
- 完善 Intel Mac 更新退出前的交接校验，交接失效时保留旧版本并提示重试。
