# 人物基础形象生成 · 约束手册

---

## 一、基础形象原则

1. **造型即灵魂** — 角色造型是核心锚点，国风3D造型，线条流畅
2. **底模即基础** — 基础打底服装 + 素颜，后续服化均为叠加层
3. **四视图一致** — 面容/体型/发型/基础服装跨视图高度统一
4. **古典气质** — 无妆状态仍需体现角色气质（典雅/温婉/英气）
5. **非人类实体** — 若角色描述指向非人类生物（神兽/仙兽/动物等），则面容/肤感/发型/服装等人类专用约束不适用，应直接依据角色描述生成该生物的视觉提示词，保留其物种特征、毛发/羽毛/鳞片质感、体型姿态、神性光环等，跳过人类专属规范

---

## 二、面容约束

> 根据角色描述（身份/性格/年龄/背景/气质）驱动 AI 生成差异化五官。每个角色必须有 distinct 脸型（方/圆/尖/长/瓜子等）和轮廓特征，禁止多角色共用相似面容。

### 通用要求

| 项目 | 约束 |
|---|---|
| 五官 | 由角色描述自然推导，根据角色身份/性格/年龄/背景生成差异化脸型与轮廓（如方脸/圆脸/尖脸/长脸/瓜子脸等），避免多角色使用同一张脸；眼型/眉型/鼻型/唇型同步差异化 |
| 风格底色 | 国风 3D 渲染、高精度建模、PBR 材质、电影级光影 |
| 气质 | 必须从角色描述提炼整体气质关键词（如典雅温婉/儒雅英气/侠骨柔情），并写入提示词 |
| 表情 | 中性微表情，符合角色气质 |

## 六、服装约束

> 角色服装应严格依据「角色描述」中的服饰描写生成。若角色描述中已指定具体服饰（如龙袍、凤袍、仙衣、官服、铠甲等），则以此为准，在提示词中准确反映其款式、颜色、图案、材质特征。
>
> 角色描述未指定服饰时，女性默认为素色古装长裙，男性默认为素色古装长衫。

### 服装推导规则

| 情况 | 处理方式 |
|---|---|
| 角色描述中含具体服饰（如龙袍/凤袍/仙衣/铠甲等） | 直接使用描述中的服饰，保留款式/颜色/图案/材质细节 |
| 角色描述仅提示身份/气质（如国王/将军/仙女） | 根据身份推导符合角色的正式服饰，不强制使用基础色 |
| 角色描述无任何服饰或身份线索 | 使用默认素色古装 |

### 着装统一规则

- 服装风格统一，确保后续服饰叠加无色彩干扰
- 除面部/手部/颈部外基本覆盖
- 四视图服装款式完全一致

## 七、四视图设定图规范

### 视图定义

| 位置 | 视图 | 角度 | 景别 | 要求 | 提示词 |
|---|---|---|---|---|---|
| 左一 | 人像特写 | 正面平视 | 头顶至锁骨 | 从头顶到锁骨完整展示，面部占60%+，五官清晰 | portrait closeup、face detail |
| 左二 | 正视图 | 正面 0° | 全身立像 | 面对镜头、双臂自然、从头顶到脚底完整展示 | front view、full body |
| 右二 | 侧视图 | 右侧 90° | 全身立像 | 纯侧面轮廓清晰、从头顶到脚底完整展示 | side view、profile、full body |
| 右一 | 后视图 | 后方 180° | 全身立像 | 后脑/背部/发尾/脚部清晰、从头顶到脚底完整展示 | back view、rear view、full body |

### 画面规范

| 项目 | 约束 |
|---|---|
| 布局 | 同一画面从左至右并排四视图 |
| 背景 | 素灰纯色 #B8B8B8 |
| 站姿 | 自然站立、双脚平行微分、双臂自然下垂 |
| 全身展示 | 全身立像必须从头顶到脚底完整入画，严禁裁切 |
| 特写展示 | 人像特写必须从头顶到锁骨完整入画，严禁裁切 |
| 表情 | 中性微表情，符合角色气质 |
| 光线 | 均匀柔光，前方主光 + 双侧补光，无硬阴影 |
| 一致性 | 四视图的肤色/体型/发型/面容/基础服装完全一致 |
| 画面比例 | 建议 4:1 或 3:1 |

## 九、约束规则

### 必守

| 编号 | 规则 |
|---|---|---|
| R1 | 必须为「素颜状态」 |
| R2 | 服装以角色描述中的服饰为准；角色描述未指定时，女性为素色古装长裙，男性为素色古装长衫 |
| R3 | 发饰/配饰须与角色身份匹配：贵族/仙子/神祇配发簪步摇/发冠；武士配束发；平民可无发饰 |
| R4 | 必须指定「素灰纯色背景」 |
| R5 | 必须指定「四视图一致性」 |
| R6 | 全身立像必须从头顶到脚底完整展示，严禁裁切 |
| R7 | 必须声明角色身高并通过头身比换算约束全身比例（女性默认 160-170cm/7头身，男性默认 175-185cm/7头身） |
| R8 | 人像特写必须从头顶到锁骨完整展示，严禁裁切头顶 |
| R9 | **非人类实体例外**：若角色描述为非人类生物（神兽/仙兽/动物等），则 R1-R8 及面容/肤感/发型/服装等人类专用约束不适用，必须使用「非人类实体模板」生成提示词 |

### 严禁

| 编号 | 严禁 |
|---|---|---|
| X1 | 无理由使用与角色描述不符的基础服装（角色描述已指定服饰时不得降级为素色古装） |
| X2 | 正顶硬光/正底光/冷色光 |
| X3 | 过度美白至无血色 / 肤色发灰 |
| X4 | 复杂场景背景（必须纯色） |
| X5 | 夸张表情/动态姿势 |
| X6 | 全身立像裁切头顶或脚底，必须从头到脚完整入画 |
| X7 | 人像特写裁切头顶，必须从头顶到锁骨完整入画 |
| X8 | 忽略身高和头身比约束，身高必须明确声明并通过头身比换算体现全身比例 |
